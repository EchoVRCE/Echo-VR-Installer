# BAC-0001: Play row occupies the top of the main panel

Status: Proposed. Governing design: [S0-7 play split](../design/s0-7-play-split.md).

Given the Play page at native 1280×720, minimum 960×540 and wide 1680×720 viewports, when it renders in PCVR or Quest mode with a normal action or a selected-target job, the green main action, blue Update/Cancel action and PCVR/Quest toggle occupy the logo band. The large logo and separate VERSION dropdown/caption are absent. The Play info band remains between the row and Community News, and no row, info, news or Server Info bounds overlap. The normal and job variants of the Install page retain their existing hero position and hit regions at all three sizes. The governing design gives the proposed coordinate bounds.

Given PCVR with a selected installed entry named A, missing installed entry named B, or catalogue entry named C, when the version menu is closed, the info band visibly identifies A, B or C respectively along with Installed, Game files missing or Not installed. During an applicable install job it keeps the selected name beside Installing and progress. Given no resolved target, it shows a separate no-selection message without inventing a version name. Optional path and server details yield space before the selected name or state; an unusually long name exposes its full text through tooltip/accessibility. A closed menu is not the visibility oracle.

Given the old Play-logo hotspot rectangle at design coordinates (574,74.4,50,126.5), clicking it after the compact row is rendered never opens the Play-logo Easter Egg dialog. If a visible new control overlaps any part of that old rectangle, it receives only its own action. No invisible hit target remains there.

Verification: compare Play PC/Quest normal/job screenshots and Install normal/job screenshots at each named size; inspect bounds, text visibility and hit regions, including the old hotspot. Select catalogue A then B with different visible names and close the menu each time; both names must be distinguishable with Not installed. Repeat for a named missing entry, a named in-progress install, and no target. A design that only hides VERSION, leaves an empty logo band, drops the name in the missing/catalogue branches, or moves Install's hero fails.
