# BAC-0002: The Play arrow selects a PC version

Status: Proposed. Governing design: [S0-7 play split](../design/s0-7-play-split.md).

Given PCVR with at least two installed/catalogue choices, no running game and no job, clicking the arrow region opens a list with installed entries, catalogue entries, the current ID checked and Install another version. Clicking the main region never opens the list; activating the arrow never dispatches the main or Update action. Choosing catalogue A and then catalogue B closes the list each time and leaves their distinct names visible with Not installed in the info band. Reopening checks the chosen entry. Choosing Install another version opens Install. In an isolated writable non-demo state, a successful save preserves the chosen ID after a page revisit and launcher restart; if saving fails, report that failure and do not claim restart persistence.

Given the three viewports in the design (1280×720, 960×540, 1680×720), the PC main, arrow and Update/Cancel regions use the design's disjoint clipped polygons. At each size, sample the interior of each region; one point on either side of x=300 and x=445; the inert divider/seam strokes; and the slanted top/bottom corners. Each interior or near-boundary point fires exactly its owning action; the strokes and outside corners fire none. The chevron, label, progress and popup anchor remain inside their assigned bounds. The popup begins below the arrow and stays inside the content column; with enough entries to exceed available height it scrolls without leaving the viewport. The play_version_menu snapshot route opens that same popup.

Given keyboard or accessibility activation, main and arrow are separately focusable and have distinct accessible names. Activating each invokes only its own action. With zero installed and zero catalogue entries, the arrow/divider are hidden and no empty popup can open. With one entry, the arrow remains available and opens a menu containing that checked entry and Install another version. Quest omits the arrow entirely.

Verification: drive pointers and pointer-free activation separately, inspect accessible metadata, compare named-size renders, use the snapshot menu route, and reload a successful real saved state. A rectangle covering the full green button, an arrow that also launches, a shared accessible target, suppression for a one-entry list, a popup at the old picker, or a status line that loses catalogue names fails.
